# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 版式模板

- 在版面上安排好格位后点「存为模板」，模板保留纸张、横竖方向、网格间距，以及每个落字格位的顺序。
- 横排按从左到右、从上到下排序；竖排按从右到左、从上到下排序。
- 右侧「版式模板」可直接发起排印、套用版式（仅切换纸张/方向/间距）或删除模板。

## 批量排印

1. 点「批量排印」或模板上的「排印」，选择模板并粘贴文字（空白自动跳过）。
2. 系统按模板格位顺序逐格套字，提交前核对字模库存：
   - 缺字（字模库没有该字）或缺量（空闲字模不够）会逐条列出缺口并停止提交；
   - 同字有多种字模时自动混合凑量，并在核对报告中说明；
   - 目标格若被其他批次占用、或换纸会裁掉批次占用格，同样阻止提交。
3. 核对通过后「确认整批落字」，整批落字带批次标记，所用字模进入占用状态。
4. 编辑期间占用不可绕过：不能点改/拖拽覆盖批次格、不能删除被占用字模、不能清空版面、换纸/套版式/存草稿/载草稿在占用期间也会被拦下。
5. 在「已提交批次」里点「整批撤销」，版面（含被覆盖的手动旧字、被收起的越界落字）与纸张设置全部回到排入前状态，字模占用同步释放。

模板、批次占用和排印结果都保存在浏览器本地，刷新后保留。字模维护、手动落字、草稿与PNG导出继续可用。
